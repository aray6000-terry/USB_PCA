推薦方式

免複雜 GCP 專案設定！只要貼上 Apps Script 網址即可雙向自動同步

員工提交申請與會計完成審核時，系統將自動背景將紀錄拋送至您的 Google 試算表；發票憑證照片亦可自動儲存至 Google 雲端硬碟資料夾。

填入您在 Google 試算表部署發布之 Web 應用程式網址
📌 3 步驟快速完成 Google 試算表配置：
  1. 在您的 Google 試算表上方選單點選「擴充功能」>「Apps Script」。
  2. 點擊下方按鈕「📋 查看 / 一鍵複製 Apps Script 腳本」，將代碼貼上替換試算表內的 Code.gs。
  3. 點擊右上角「部署」>「新部署」，類型選擇「網頁應用程式」，並將「誰可以存取」設為「所有人 (Anyone)」，複製產生的 /exec 網址貼回上方即可！

💡 GCP Service Account 官方 API 架構說明

  • 全後端隔離：私鑰安全存放於伺服器後端，網頁端嚴格遮蔽不外洩。
  • 多重容錯：即使未設定 Google API，系統仍以本機安全資料庫確保 100% 穩定運作。
